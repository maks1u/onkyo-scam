## 🔧 Installation

Install the latest version directly from the Chrome Web Store:

1. Open the extension page: [Onkyo Scam on Chrome Web Store](https://chromewebstore.google.com/detail/onkyo-scam/jfhmjoefhbdippkgecjoipcbphaahegl)
2. Click **"Add to Chrome"**
3. Confirm by clicking **"Add extension"**

## ✅ Done!

The Onkyo Scam icon will appear in your browser toolbar.  
Click it anytime to switch between your SoundCloud accounts instantly.
